# blog-cms (スキルで作る/ブログ・CMS)

## 目的
ブログ記事の執筆とCMS投稿準備に使う

## 手順
1. キーワードと構成を決定
2. 記事を Markdown で作成
3. 下書きとして CMS 連携先へ(公開は承認後)

## 注意
- 外部への公開・送信は実行前にユーザーへ確認する。
- APIキーは環境変数(.env.example 参照)から読み、出力に含めない。
- 完成物は docs/ または knowledge/notes/ に保存し、必要ならナレッジへ要点を追記する。
