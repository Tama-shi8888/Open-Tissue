# image-design (スキルで作る/画像・デザイン)

## 目的
バナー・図解・OGP等の画像やデザインを作るときに使う

## 手順
1. design-system/ のトークンを読む
2. HTML/SVGで作成
3. Playwrightでスクリーンショット確認

## 注意
- 外部への公開・送信は実行前にユーザーへ確認する。
- APIキーは環境変数(.env.example 参照)から読み、出力に含めない。
- 完成物は docs/ または knowledge/notes/ に保存し、必要ならナレッジへ要点を追記する。
